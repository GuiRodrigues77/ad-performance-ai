# 📊 AdPerformance AI

Dashboard desenvolvido em Python para análise automatizada de campanhas de tráfego pago.

## 🚀 Sobre o projeto

O AdPerformance AI foi desenvolvido como um projeto de estudo para aplicar conceitos de:

- Python
- Pandas
- Streamlit
- Plotly
- Análise de dados
- Automação
- Métricas de tráfego pago

O sistema recebe dados de campanhas através de um arquivo CSV e realiza automaticamente o processamento e a análise dos resultados.

## ⚙️ Funcionalidades

- Upload de arquivos CSV
- Cálculo automático de métricas
- CTR
- CPC
- CPM
- CPA
- Taxa de conversão
- ROAS
- Classificação automática das campanhas
- Recomendações baseadas nos resultados
- Dashboard interativo
- Gráficos de desempenho
- Filtro por classificação
- Análise automática de campanhas

## 🧠 Como funciona

O fluxo principal do sistema é:

CSV → Pandas → Métricas → Classificação → Análise → Recomendação

Os dados são processados automaticamente e apresentados em um dashboard desenvolvido com Streamlit.

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Streamlit
- Plotly
